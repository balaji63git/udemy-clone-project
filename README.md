# 🎓 Udemy Clone

This is a **Udemy clone project** built using **HTML and CSS (Flexbox)** to replicate the layout and design of the Udemy platform.
The project focuses on practicing responsive design, layout structuring, and styling with modern CSS techniques.

## 🚀 Features

* Responsive homepage layout
* Navigation bar with logo and menu links
* Course cards section with flexible grid design
* Categories and featured sections styled like Udemy
* Fully built using **Flexbox** for alignment and positioning

## 🛠️ Tech Stack

* **HTML5** – for structure
* **CSS3 (Flexbox)** – for styling and layout
